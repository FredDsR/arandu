# Scaffolding Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Judge every generated CEP pair with `QAJudge` before it can scaffold later pairs, keep rejected pairs in the output, and persist the verdict on the pair so `judge-qa --resume` skips it.

**Architecture:** `BloomScaffoldingGenerator` receives an optional `PairValidator` (a `Protocol` that `QAJudge` already satisfies). Each pair is judged right after generation against the same grounding `judge-qa` uses (`build_pair_judge_context`), and one method, `_scaffolding_pool`, decides which prior pairs reach the prompt (`is_valid is True`). `CEPQAGenerator` only forwards the validator; `qa/batch.py` builds it from `JudgeConfig` through a single `_build_cep_generator`, and records the effective state on each `QARecordCEP` and a judge snapshot in the `cep` run metadata.

**Tech Stack:** Python 3.13, Pydantic v2 / pydantic-settings, Typer, pytest + pytest-mock, Ruff, uv, bash (SLURM/Podman), Docker Compose YAML.

**Spec:** `docs/superpowers/specs/2026-10-14-scaffolding-gate-design.md`

## Review Focus

1. Validator raises (network down, judge crash): the pair must stay in the output, unjudged (`validation is None`), and must not be admitted to scaffolding; the chunk must not abort. Test in Task 2 (`test_gate_exception_keeps_pair_unjudged`).
2. Generation LLM echoes a `validation` key in its JSON: it must never become a verdict, with or without the gate, otherwise `judge-qa --resume` would trust a fabricated verdict. Test in Task 2 (`test_parse_response_ignores_echoed_validation`).
3. `enable_reasoning_traces=True`: the Module II enricher rebuilds the pair field by field and silently drops the verdict (`reasoning.py:130`). Test in Task 3 (`test_enrich_preserves_validation_and_rationale`).
4. Gate flag on but `enable_scaffolding_context=False`: no validator is built, no judge calls are made, no validator model is required, and the record says `scaffolding_gate_enabled=False`. Tests in Task 1 (`test_gate_inactive_without_scaffolding_needs_no_validator`) and Task 4 (`test_build_cep_generator_skips_validator_without_scaffolding`).
5. Gate on, no `ARANDU_JUDGE_VALIDATOR_MODEL` in env or `.env`: the CLI must exit 1 before any LLM call and before `run_batch_cep_generation`. Test in Task 5 (`test_gate_without_validator_model_exits_before_batch`).

def _verdict(*, passed: bool, error: str | None = None) -> JudgePipelineResult:
    """One-criterion CEP verdict; a criterion error makes it fail like the real pipeline."""
    criterion = CriterionScore(
        score=1.0 if passed else 0.0, threshold=0.5, rationale="r", error=error
    )
    step = JudgeStepResult(criterion_scores={"faithfulness": criterion})
    return JudgePipelineResult(stage_results={"cep_validation": step}, passed=step.passed)


class _GateByQuestion:
    """PairValidator double that rejects the questions listed in ``reject``.

    ``outcome`` switches every call to an errored verdict (``"error"``), no
    verdict (``"none"``, mirrors QAJudge swallowing an exception) or a raise
    (``"raise"``).
    """

    def __init__(self, reject: set[str] | None = None, outcome: str = "verdict") -> None:
        self.reject = reject or set()
        self.outcome = outcome
        self.calls: list[tuple[QAPairCEP, str]] = []

    def validate(self, qa_pair: QAPairCEP, context: str) -> QAPairCEP:
        self.calls.append((qa_pair, context))
        if self.outcome == "raise":
            raise RuntimeError("judge down")
        if self.outcome == "none":
            return qa_pair
        error = "llm down" if self.outcome == "error" else None
        passed = qa_pair.question not in self.reject
        return qa_pair.model_copy(update={"validation": _verdict(passed=passed, error=error)})

        return GenerateResult(
            content=_valid_pair_json(question=f"Question {n}?", answer=f"Answer {n}.")

```python
    def _scaffolding_pool(self, pairs: list[QAPairCEP]) -> list[QAPairCEP]:
        """Select the prior pairs allowed to scaffold the next prompt.

        Without a validator every pair is eligible (legacy behavior). With one,
        only approved pairs are: an unjudged pair (``is_valid is None``) or a
        verdict with a criterion error (the ``cep_validation`` filter stage turns
        it into ``passed=False``) stays out.

        Args:
            pairs: Pairs generated so far for this chunk, in generation order.

        Returns:
            The eligible pairs, in the same order.
        """
        if self.validator is None:
            return pairs
        return [pair for pair in pairs if pair.is_valid is True]

    def _judge(self, pair: QAPairCEP, judge_context: str) -> QAPairCEP:
        """Run the scaffolding gate on one pair.

        Args:
            pair: Freshly generated pair (no verdict).
            judge_context: Grounding built by ``build_pair_judge_context``.

        Returns:
            The judged pair, or the pair unchanged when there is no validator or
            the validator raised (it then stays unjudged and is not admitted).
        """
        if self.validator is None:
            return pair
        try:
            return self.validator.validate(pair, judge_context)
        except Exception:
            logger.warning(
                "Scaffolding gate failed on a %s pair; keeping it unjudged",
                pair.bloom_level,
                exc_info=True,
            )
            return pair
```

6. Replace `_generate_for_level` with:

```python
    def _generate_for_level(
        self,
        context: str,
        bloom_level: str,
        num_questions: int,
        *,
        prior_pairs: list[QAPairCEP] | None = None,
        source_metadata: SourceMetadata | None = None,
        judge_context: str = "",
    ) -> list[QAPairCEP]:
        """Generate QA pairs for a specific Bloom level.

        Generates one QA pair per LLM call to ensure consistent quality and
        clean attribution of model thinking traces to individual pairs. Each
        pair goes through the scaffolding gate before a sibling can see it.

        Args:
            context: Source text context.
            bloom_level: Bloom taxonomy level.
            num_questions: Number of questions to generate.
            prior_pairs: Admitted pairs from lower levels for scaffolding context.
            source_metadata: Optional source metadata for prompt enrichment.
            judge_context: Grounding passed to the validator (unused without one).

        Returns:
            List of QAPairCEP objects, judged when a validator is set.
        """
        pairs: list[QAPairCEP] = []
        all_prior_pairs = prior_pairs if prior_pairs else []

        for pair_index in range(num_questions):
            # Build scaffolding context from prior pairs (including current level);
            # downstream formatting may truncate to max_scaffolding_pairs.
            current_prior = all_prior_pairs + self._scaffolding_pool(pairs)

            prompt = self._build_prompt(
                context,
                bloom_level,
                prior_pairs=current_prior,
                source_metadata=source_metadata,
            )

            try:
                pair = self._generate_single_pair(
                    prompt=prompt,
                    context=context,
                    bloom_level=bloom_level,
                )
            except LLMResponseError:
                logger.warning(
                    "Retries exhausted for pair %d/%d at %s level; skipping",
                    pair_index + 1,
                    num_questions,
                    bloom_level,
                    exc_info=True,
                )
                continue
            except Exception as e:
                logger.error(
                    "Failed to generate pair %d/%d for %s level: %s",
                    pair_index + 1,
                    num_questions,
                    bloom_level,
                    e,
                )
                continue

            pairs.append(self._judge(pair, judge_context))
            logger.debug(
                "Generated pair %d/%d at %s level",
                pair_index + 1,
                num_questions,
                bloom_level,
            )

        if len(pairs) < num_questions:
            logger.warning(
                "Generated %d/%d pairs for %s level (some failed)",
                len(pairs),
                num_questions,
                bloom_level,
            )

        return pairs
```

    qa_config: QAConfig,
    cep_config: CEPConfig,
    judge_config: JudgeConfig,

    Single construction path for both the parallel worker initializer and the
    sequential path.

    Args:
        qa_config: QA configuration (generation provider, model, endpoints).
        cep_config: CEP configuration (decides whether the gate is active).
        judge_config: Judge configuration for the gate's validator client.

    Returns:
        A ready ``CEPQAGenerator``.

    Raises:
        ValueError: If the gate is active and no validator model is configured.
    """
    from arandu.qa.cep import CEPQAGenerator

    # Only fall back to ollama_url when provider is ollama
    base_url = qa_config.base_url
    if not base_url and qa_config.provider == "ollama":
        base_url = qa_config.ollama_url

    llm_client = LLMClient(
        provider=parse_provider(qa_config.provider),
        model_id=qa_config.model_id,
        base_url=base_url,

def _scaffolding_gate_snapshot(cep_config: CEPConfig, judge_config: JudgeConfig) -> dict:
    """Describe the scaffolding gate for the ``cep`` run metadata.

    Mirrors what ``judge-qa`` snapshots (judge settings, per-criterion threshold
    and prompt digest, Bloom descriptions digest), because verdicts written at
    generation time have no ``judge_qa/run_metadata.json`` of their own.

    Args:
        cep_config: CEP configuration.
        judge_config: Judge configuration used by the gate.

    Returns:
        ``{"enabled": False}`` when the gate is inactive, else the snapshot.
    """
    if not cep_config.scaffolding_gate_active:
        return {"enabled": False}

    from arandu.qa.cep.judge_run import (
        BLOOM_DESCRIPTIONS_DIR,
        snapshot_bloom_descriptions,

    return {

        "judge": judge_config.model_dump(mode="json"),
        "criteria": {name: snap.model_dump(mode="json") for name, snap in criteria.items()},
        "bloom_descriptions_sha256": snapshot_bloom_descriptions(
            BLOOM_DESCRIPTIONS_DIR, judge_config.language
        ),
    }
